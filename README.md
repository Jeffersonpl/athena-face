
# 🏛️ Athena Face

**Microserviço Multi-Tenant de Reconhecimento Facial**

Sistema de reconhecimento facial de alta performance usando InsightFace, FastAPI e Docker.

---

## ✨ Features

- ✅ **Multi-Tenancy**: Isolamento total por cliente
- ✅ **Reconhecimento Facial**: InsightFace (buffalo_l)
- ✅ **Liveness Detection**: Anti-spoofing básico
- ✅ **API RESTful**: FastAPI com documentação automática
- ✅ **Rate Limiting**: Proteção contra abuso
- ✅ **Docker**: Deploy simplificado
- ✅ **Logs Estruturados**: Auditoria completa
